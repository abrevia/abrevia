Cryptographic Proof: AES-256 Encryption

How Abrevia verifies and guarantees encrypted data security

🗄️ 1. Storage at Rest (Database & Disks) FIPS 140-2

All Abrevia conversation records, tickets, and contacts are stored in PostgreSQL on AWS managed by Supabase. Every underlying Amazon EBS block storage volume is encrypted at rest using industry-standard XTS-AES-256 via AWS Key Management Service (KMS).

View Supabase SOC 2 Type II & Security Compliance →
🌐 2. Data in Transit (Network Security) TLS 1.3

Every connection between your browser, the serverless edge, and databases is enforced over HTTPS with TLS 1.3 encryption using modern AES-GCM ciphers (e.g. TLS_AES_256_GCM_SHA384). You can verify this independently in your browser by clicking the padlock icon in the address bar.

📱 3. Cellular Gateway Cipher (E2EE) AES-256-CFB

Abrevia includes open-source AES-256 ciphering in lib/cipher.js with SHA-256 key derivation matching the hardware Keystore specification of Android cellular gateways. Outbound payloads are encrypted before leaving the server.

Inspect lib/cipher.js source code on GitHub →
How You Can Verify This Independently:
  • Inspect TLS cipher in browser: Address bar → Security → Certificate Details.
  • Audit the open-source backend code at github.com/serviciosadg/abrevia.
  • Review our published Privacy Policy and Terms of Service.
